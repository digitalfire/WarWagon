# Documentation as code

**Decision:** Git-tracked Markdown, Mermaid, RFCs and ADRs in the same repository as code. PRs provide review and traceable history. A generated documentation site may be added later without moving the source of truth.

**Reasoning:** Maintainers and AI agents need stable paths, versioned decisions and an exact implementation baseline.
