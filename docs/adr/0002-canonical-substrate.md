# Canonical intelligence substrate

**Proposal:** one versioned canonical event/knowledge store, with adapters and graph/search projections instead of framework-owned sources of truth.

**Alternatives:** one existing framework's database, federated engine stores, or a purpose-built canonical schema.

**Decision:** UNDECIDED pending ingestion, query latency, fault recovery, provenance and migration benchmarks.
