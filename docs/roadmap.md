# Implementation roadmap

**0 — Foundation:** docs-as-code, open ADRs, graph ontology and protocol proposals, initial task dependency graph.  
**1 — Intelligence kernel:** goal compiler, mock planners, opportunity frontier and knowledge ledger.  
**2 — Durable agent runtime:** specialist profiles, messaging, leasing, checkpoint and recovery tests.  
**3 — Evidence and evaluation:** reproducible local fixtures, independent verification and strategy tournaments.  
**4 — Adapter ecosystem:** model providers, MCP, external security-engine adapters.  
**5 — Operational platform:** user console, release packaging, monitoring, testing and community processes.

## First acceptance demonstration
Three specialists collaborate over one goal in a controlled fixture, maintain shared grounded state, survive a worker failure and produce an independently verified trace. Measure two competing planners. No production capability claims until this runs.

Detailed backlog reconciliation remains to be completed; older generated task-counts are planning estimates, not issue completion.
